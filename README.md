# Material for MkDocs 中文文档

本项目是 [Material for MkDocs](https://github.com/squidfunk/mkdocs-material) 的中文文档，译文以 9.6.14 版为基准。站点地址：[Material for MkDocs 中文文档](https://leafcxy.github.io/mkdocs-material/)。

## 本地构建

使用 Python 3.12。建议先激活一个虚拟环境，再安装本站依赖：

```bash
python -m pip install -r requirements.txt
```

启动本地预览：

```bash
python -m mkdocs serve
```

检查文档能否通过严格构建：

```bash
python -m mkdocs build --strict
```
