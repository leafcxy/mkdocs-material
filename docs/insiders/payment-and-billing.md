# 付款和账单

由于我们在GitHub上托管我们的存储库，包括MkDocs的材料
社区版和私人Insiders版，[GitHub赞助商]是
非常适合处理所有金融交易以及访问
管理Insiders存储库。

因此，要成为Material for MkDocs的赞助商，必须拥有[GitHub帐户]。

  [GitHub Sponsors]: https://github.com/sponsors
  [GitHub account]: https://docs.github.com/en/get-started/start-your-journey/creating-an-account-on-github

## 付款

GitHub赞助商目前只接受信用卡付款，因为他们
2023年初，[取消了对PayPal的支持]。什么时候？
输入您的信用卡详细信息，确保该卡在[有效期]内保持有效
延长期限]以防止对您的赞助造成任何干扰。

  [valid over an extended period]: runtime-and-cancellation.md#automatic-cancellation
  [removed support for PayPal]: https://github.blog/changelog/2023-01-23-github-sponsors-will-stop-supporting-paypal/

## 发票

GitHub赞助商在以下时间通过电子邮件自动发出并发送付款收据
每个计费周期。这些收据作为付款确认，而不是
正式发票。由于所有交易都由[GitHub赞助商]管理，GitHub是
您负责付款和账单事宜的主要联系人，而不是我们。

如果您需要我们提供正式发票以供记录，请联系我们
与我们在sponsors@squidfunk.com在发起赞助之前。

## 计费周期

[计费周期]是GitHub上的帐户级别设置，设置为每月一次
或每年。它可以随时更改，因此您可能需要检查设置
在赞助之前，根据您的需求将其更改为每月或每年
您自己或您所在组织的偏好。

如果出于任何原因，您无法更改计费周期
解决方案是创建一个专用的[GitHub bot帐户]，在其中设置计费
相应地循环使用，并专门用于您的赞助捐款。
这是我们许多组织赞助商成功实施的一项战略
实施。

如果您在赞助之前遇到任何困难或有其他问题，
请随时与我们联系sponsors@squidfunk.com对于额外
支持。
