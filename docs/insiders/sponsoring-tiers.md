# 赞助级别

我们提供一系列针对我们不同需求量身定制的赞助级别
社区。无论你是个人用户，还是扎根于学术界，或者在
一个在商业上使用我们软件的组织，有一个赞助层
这符合你的需要。

## 选择一个层级

选择合适的赞助级别取决于您的需求以及您打算如何
使用MkDocs内部人员的材料。我们的级别分为[非商业]
和[商业]用途：

  - __非商业层__: 适用于个人、开源项目、，
    学术用途
  - __商业层__: 专为任何规模的组织和企业设计

每个[每月赞助级别]都根据您的需求提供一系列福利。
好处包括访问我们的私人MkDocs Insiders材料库，
优先处理错误报告等，具体取决于
您打算使用它构建的项目[^1]和所需的合作者。
请记住，您始终可以[升级或降级]您的
任何时候的赞助级别。

  [^1]:
    项目被定义为具有“mkdocs.yml”配置文件的文件夹
    它是用MkDocs Insider的Material构建的。这是唯一的限制
    遵循文档页数或项目大小
    随你。

## 自定义金额

我们邀请您通过GitHub赞助商贡献自定义赞助金额，
使您能够根据自己的喜好支持MkDocs的Material。
请注意，个人需要每月至少认捐15美元
访问内部人员，而鼓励组织每月赞助125美元或
更多，根据他们的要求。

非常感谢超过这些门槛的捐款。请注意
一次性捐款，无论规模大小，都不会被授予
由于技术限制，内部人士。

## 切换层

您可以轻松地在不同的赞助级别之间切换——[升级]或
[降级]——随时。只需访问@squidfunk
[GitHub赞助商简介]并调整您的赞助级别选择。一次
你已经做出了改变，你将立即在新的级别上赞助。

如果您超过当前赞助限额内的项目数量，我们
敬请您将赞助升级到更高级别以保留
MkDocs内部人员访问材料。该更改立即生效，
金额根据您的[计费周期]按比例分配。
