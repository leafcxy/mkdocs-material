# 设置

Material for MkDocs 提供了广泛的自定义选项，让您可以根据需要定制文档。在本节中，我们将解释如何为您的网站创建有意义的结构、更改外观、添加博客和评论系统，以及构建高度优化的网站。

## 网站结构

通过配置页眉和页脚、选择多种导航模式、设置网站搜索等方式，设置和自定义文档结构。

<div class="grid cards" markdown>

- :fontawesome-solid-earth-americas: __[语言]__ – 从 60 多种支持的语言中选择或添加新语言
- :material-page-layout-sidebar-left: __[导航]__ – 创建清晰、简洁和全面的导航结构
- :material-page-layout-header: __[页眉]__ – 自定义页眉行为，添加公告栏
- :material-page-layout-footer: __[页脚]__ – 在页脚中添加社交媒体资料或网站链接
- :material-tab-search: __[搜索]__ – 设置和配置搜索，完全在用户浏览器中运行
- :material-tag-plus-outline: __[标签]__ – 使用标签对页面进行分类并分组相关页面

</div>

  [语言]: changing-the-language.md
  [导航]: setting-up-navigation.md
  [页眉]: setting-up-the-header.md
  [页脚]: setting-up-the-footer.md
  [搜索]: setting-up-site-search.md
  [标签]: setting-up-tags.md

## 外观

通过几行配置即可匹配您的品牌颜色、字体、图标、徽标等 - Material for MkDocs 使扩展基本配置或更改外观变得简单。

<div class="grid cards" markdown>

- :material-brush-variant: __[颜色]__ – 使用现有调色板更改颜色或使用 CSS 自定义
- :material-format-font: __[字体]__ – 从 1,000 多种 Google 字体中选择或加载自托管字体
- :material-google-downasaur: __[徽标和图标]__ – 更改徽标，使用 8,000 多个图标中的任何一个，或添加新图标
- :material-cards-variant: __[社交卡片]__ – 在分享链接时自动创建社交媒体预览

</div>

  [字体]: changing-the-fonts.md
