# 教程

除了基本的入门指南外，我们还提供旨在
展示如何在不同用例中使用MkDocs的Material。与…对比
入门指南或参考文档，教程显示
MkDocs材料中可用的功能范围，以及
更广泛的MkDocs生态系统。

教程将指导您完成工作示例，因此通过遵循这些示例，您应该
不仅要了解如何使用Material for MkDocs，还要
您自己项目的模板。为了方便起见，这些模板也是
可作为GitHub上的模板存储库使用。

教程假设您已经安装了[public version]或
[Insiders edition]Material for MkDocs，您已经完成了
[creating your site]设置指南。

请注意，如果我们使用的功能需要Insiders版本，我们会标记这些
带有心形图标： `sponsors` 如果您使用的是公共版本
那么你可以跳过这些步骤。有时会有一些方法来实现
公开版和内幕版的目标相同。在……里面
在这种情况下，我们将在选项卡视图中显示它们，以便您可以看到其中一个。
